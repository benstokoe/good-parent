# Adopt NativeWind + React Native Reusables as the styling and component layer

`DESIGN.md`/`CLAUDE.md` left the implementation of GoodParent's design tokens (colors, typography, spacing, elevation — all framework-agnostic and fixed) deliberately open: a plain `theme.ts` constants file, NativeWind, or a fuller system like Tamagui/Restyle. We chose NativeWind (Tailwind-style utility classes over React Native, backed by the token set) plus React Native Reusables — a shadcn/ui-style, copy-paste (not npm-installed) component library built on NativeWind — as the concrete answer.

We considered a plain `theme.ts` module (least machinery, no new dependency) and a fuller design-system library like Tamagui or Restyle (more built-in structure, own theming/variant system). We chose NativeWind + React Native Reusables instead because copy-paste components mean the source lives in this repo and can be edited freely to match `DESIGN.md`'s exact rules (capsule buttons only, `lg`/12px card radius, no borders on filled cards, etc.) rather than fighting a third-party component API, while still giving Tailwind-config-level token consumption across iOS, Android, and web (see `docs/adr/0005` for web becoming a real target) from one config. The trade-off: adopting a whole styling paradigm (utility classes, NativeWind's build-time transform) is harder to reverse than a plain constants file would have been, and every component now carries a dependency on React Native Reusables' patterns and conventions rather than being hand-rolled.

**Consequences:**
- `DESIGN.md`'s tokens (colors, typography, spacing, radius, shadows) get ported into the NativeWind/Tailwind config as the source of truth — not redesigned, not re-tuned, per the existing "ported as-is" instruction in `CLAUDE.md`.
- `@expo/ui` is explicitly not used alongside this: its components render native SwiftUI/Jetpack Compose views with their own styling API that NativeWind's `className` cannot reach, which would fight the bespoke (non-native-chrome) visual identity `DESIGN.md` specifies, and it requires a dev client — breaking Expo Go testing, which this project relies on.
